反向传播算法，这是神经网络学习中的核心算法，理解这个非常重要。

所谓学习，就是去找到特定的权重和偏置值，使得代价函数最小，寻找的方法中需要使用到梯度下降。

说到这里，引入一下梯度。

当一个函数中有多个变量，单独一个导数是不可行的，不能预测多元函数的走向，比如：f(x, y) = x^2 + y^2。

在多元函数中有偏导数的概念，意思是将一个变量作为变量，其他变量作为常数，对变量求导得到的就是偏导数。

而由偏导数组成的向量就被称为梯度。上述的 f(x, y) 的梯度 ∇f = (∂f/∂x, ∂f/∂y) = (2x, 2y)。在 (1, 2) 处，∇f(1, 2) = (2, 4)，这个向量的含义：x 方向上升速度是 2，y 方向上升速度是 4。

显然，我们只需要将 (1, 2) 的 1 和 2 都调小就可以使得 f(x, y) 的值变小了，也就是朝着与梯度中正数部分相反的方向调整值，和导数的含义是一样的。

并且，梯度不仅仅表示函数在某点的变化趋势，还含有变化的影响程度，(1, 2) 让其在 y 上和在 x 上移动相同的大小，影响更大的必然是 y。 

在神经网络学习中，虽然 cost function 中有大量的参数，但是使用上述的梯度下降，还是可以将 cost function 的输出降至最低，从而得到一个表现较好的模型。

在训练开始时，各个参数和偏置值都是随机的，输入一个图片，输出层的输出大概率是很混乱的，根本无法得到准确的结果。

我们需要不断地修改权重和偏置值以到达 cost function 的最小值。
