神经网络是一个包含大量参数的函数。

一个可行的模型就是通过训练将各个参数确定下来，并可以对未知的输入得到理想的输出。

如何训练一个神经网络呢？需要使用到梯度下降。

引入一个概念：cost function —— 成本函数，表示模型输出的结果和理想结果之间的差异。

cost function 输入的是模型的所有参数，输出的是一个 cost 值，我们需要让 cost 最小。

所以，此时问题就是如何通过 cost function 的输出训练模型中的参数和偏置值。

使用二元函数进行理解，二元函数是一个三维的形状，求其最小值，相当于在一个地形上求海拔最低的点，我们可以随机放置到一个位置，求解这个位置的梯度。

得到梯度，就可以知道走哪个位置可以使得这个函数值变小。这里的 cost function 虽然有成千上万个参数和偏置值，但调整的原理和二元函数是一致的。

但是，使用这个方法可能会导致陷入局部最小值。

上一节提到的隐藏层学习模式需要进行修改，隐藏层的真正使命不是产生人类看得懂的中间表示，而是在高维空间里做一次坐标变换——把原本线性不可分的数据（原始像素空间里不同数字互相缠绕）映射到一个新的空间，让它们在这个新空间里可以被一条直线干净地分开。

至于变换后的那些维度分别代表什么，模型不关心，人也看不懂。它只要能完成分类这个目标就够了。
